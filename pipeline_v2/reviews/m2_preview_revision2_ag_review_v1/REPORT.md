### 3.2 Key Algorithmic Fixes in `pipeline_v2/navigation/core.py`
1. **Meaningful Alphanumeric Content Start (`_content_start`, lines 66–77):**
   - Strips leading UTF-8 BOM and paragraph marker (`^\[[0-9]+\]`), then scans line-by-line until it finds a line where `any(ch.isalnum() for ch in PLACEHOLDER.sub("", value))` is true.
   - Skips lines containing only `<FRAGMENT_SUPPRESSED>` / `<REFERENCE_SUPPRESSED>`, parentheses, punctuation, or leader dots (`...`). Returns `None` if the entire unit has zero alphanumeric characters outside marker/placeholders.
2. **Word- and Tag-Safe Bounded Window (`_safe_window`, lines 88–138, & `_opening`, lines 141–145):**
   - Replaces the old `SENTENCE_END` regex with a bounded `240`-codepoint window inside `[floor, content_end]`.
   - Protects all `PROTECTED_TAG` spans (`<[^<>\r\n]+>|\((?:FRAGMENT|REFERENCE|DATE)_SUPPRESSED\)`) from being cut on either side, and snaps to whitespace/non-alphanumeric boundaries so words are not split across `a` or `b` unless a single token or tag exceeds `240` characters.
3. **Why `v2` Failed on 9 Cases and Why `v3` Fixed It (`_anchor_candidates`, lines 148–161):**
   - In `v2`, when generating the tail candidate for a quote cue longer than `240` characters, `_anchor_candidates` pre-clipped the cue span to `(max(a, b - max_chars), b)` **before** calling `_safe_window`. In `9` units where a `<FRAGMENT_SUPPRESSED>` tag straddled `b - 240` (and `245` units where a word straddled `b - 240`), `_safe_window` treated the pre-clipped start as the anchor boundary `a` and could not move `left` past `a`, clipping right through `<FRAGMENT_SUPPRESSED>` (e.g., `"MENT_SUPPRESSED>"`, `"RAGMENT_SUPPRESSED>"`).
   - In `v3`, `_anchor_candidates` passes the **full original cue span `(a, b)`** into `_safe_window(text, cs, ce, a, b, max_chars, max(a, b - max_chars), b, floor=floor)`. Because `a` is now the true start of the quote cue, `_safe_window` sees `a < x < left < y` for the straddling `<FRAGMENT_SUPPRESSED>` tag (or word) and advances `left` cleanly to `y` (after the tag/word) and strips leading whitespace.
4. **Bidirectional Containment, Merge-Within-240, and Novel Slot-2 Selection (`_add_window` & `_select_preview_spans`, lines 164–206):**
   - Opening window (`Slot 1`) is added first (`_opening` when `content_start is not None`, else first anchor candidate).
   - `_add_window` rejects any candidate contained in an existing window (`left <= a and b <= right`), replaces an existing window if the new window contains it (`a <= left and right <= b`), and merges overlapping windows when `min(a, left) >= content_start` and `max(b, right) - min(a, left) <= max_chars`.
   - `Slot 2` scores all anchor candidates by `(added_full, added_chars, added_partial, 1 if kind == "quote_introduction_candidate" else 0, -a)` and adds the highest-scoring candidate only if `added_full > 0 or added_chars > 0 or added_partial > 0`.
