## Lệnh thực tế sau khi code được freeze

Tất cả lệnh từ `E:/Git/coliee-case-retrieval`. Local dependencies có trong `.venv` hiện tại; file version `pipeline_v2/requirements-m3-local.txt` không yêu cầu torch/transformers trên Windows.

Tạo plan mới (chỉ local, không inference). Nếu run đã tồn tại, dùng tên mới; không ghi đè:

```powershell
& .venv/Scripts/python.exe -m pipeline_v2.m3 plan --output pipeline_v2/artifacts/TEN_RUN_MOI
```

Các lệnh sau **dành cho AG chạy thử khi cần**, sau Docker sẵn sàng và Modal đăng nhập; dùng đúng run đã được khóa, ví dụ `m3_pilot_20261106_l4_v1`. Lệnh deploy/preflight/run/search có thể phát sinh remote inference thực, không phải dry run:

```powershell
& .venv/Scripts/python.exe -m pipeline_v2.deploy_modal deploy
& .venv/Scripts/python.exe -m pipeline_v2.deploy_modal m3 preflight --run-dir pipeline_v2/artifacts/m3_pilot_20261106_l4_v1
& .venv/Scripts/python.exe -m pipeline_v2.deploy_modal m3 run --run-dir pipeline_v2/artifacts/m3_pilot_20261106_l4_v1 --stop-after-batches 1
& .venv/Scripts/python.exe -m pipeline_v2.deploy_modal m3 run --run-dir pipeline_v2/artifacts/m3_pilot_20261106_l4_v1
& .venv/Scripts/python.exe -m pipeline_v2.deploy_modal m3 verify --run-dir pipeline_v2/artifacts/m3_pilot_20261106_l4_v1 --restore-test
```

`run` sau stop tự dùng cache đã commit, upsert DB idempotent. Không có lệnh embed full trong bản pilot này. Thực hiện verify sau khi restart container để kiểm persistence, giữ kết quả trước/sau trong immutable operation receipts. Restore test tạo collection suffix `_restore`, không ghi đè nếu đã tồn tại; không lặp `--restore-test` trên cùng run, dùng `verify` không flag để kiểm tiếp.

Tìm kiếm và mở nguồn:

```powershell
& .venv/Scripts/python.exe -m pipeline_v2.deploy_modal m3 search --run-dir pipeline_v2/artifacts/m3_pilot_20261106_l4_v1 --query "standard of review" --limit 10
& .venv/Scripts/python.exe -m pipeline_v2.m3 literal --run-dir pipeline_v2/artifacts/m3_pilot_20261106_l4_v1 --text "Federal Court" --ignore-case
& .venv/Scripts/python.exe -m pipeline_v2.m3 open --run-dir pipeline_v2/artifacts/m3_pilot_20261106_l4_v1 --passage-id PASSAGE_ID_TRONG_PLAN
```

`search --query-case 012345.txt` loại query case trước cap; ID phải đúng filename canonical của nguồn. Search chỉ pilot universe; BM25 case dùng **toàn raw selected cases**, BM25/dense passage dùng đúng core bodies M2 được chọn. Unicode/digits/negation giữ qua analyzer không bỏ stopwords. Fusion best passage -> unique cases -> RRF equal3channels/k60; không cộng overlap thành votes. Dense reference dùng exact cosine và xử lý ties. Literal trả raw byte spans; normalized text không dùng làm quote.

## Artifacts và trạng thái

- `pilot_manifest.json`, `manifest.sha256.json`: IDs/input/source/profile/code fingerprints bất biến, không sửa lại để chấp nhận code/profile drift. Sau fix ảnh hưởng implementation cần plan mới.
- `ledger.sqlite3`: từng attempt, lỗi/retry/unknown usage, input tokens, safe response metrics/padding/remote latency. Không biết token consumption khi request thất bại thì null, không giả0.
- `vectors/*.npz` + metadata: vector gốc ngoài DB, IDs/hash/profile được nhúng trong shard; atomic writes, orphan hợp lệ có thể phục hồi không inference. Corruption phải fail-stop. Run lock nhả khi process chết, không đồng thời hai writer trên một run.
- `preflight.json`, `progress.json`, `run_result.json`, `verification.json`: latest-state pointers; `operations/*.json` giữ kết quả/error từng CLI call bất biến. Preflight mới bắt đầu vô hiệu PASS cũ; lỗi không để dùng lại PASS đó.
- Injected fake backend được ghi `simulated`; unit PASS không phải real pilotPASS. `run` đủ vectors chỉ là `vectors_ingested_verified_not_full_pilot_acceptance`; còn search/reference, restore/restart và kiểm độc lập. `verify` là DB/reference scope, không tự chứng nhận toàn pilot hay retrieval quality.
